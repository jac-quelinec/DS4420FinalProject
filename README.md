# DS4420FinalProject
Utilizing MultiLayer Perceptron and Collaborative Filtering to Explore Food Insecurity in the U.S. 

Instructions on how to run our streamlit app:
1. From github, download our main branch as a zip
2. Open the zip and in a terminal window navigate to: ./Downloads/DS4420FinalProject-main
3. Once you're in the folder, run: streamlit run Our_Project.py
4. This should prompt you to: http://localhost:8501
